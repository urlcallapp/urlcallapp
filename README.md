# urlcallapp

קישורי HTTP לחיצים שמפעילים פעולות native במכשיר — בלי אפליקציה, בלי שרת, בלי הרשמה.

יוצרים קישור בממשק צבעוני, שולחים אותו, ומי שפותח מקבל מיד הצעה לפעולה:
- 📞 **שיחה** (`tel:`)
- 💬 **SMS** (`sms:`) עם אפשרות להודעה מוכנה מראש
- 🟢 **וואטסאפ** — קישור click-to-chat רשמי (`wa.me`): מספר + הודעה מוכנה מראש, או הודעה בלבד והנמען נבחר בוואטסאפ
- ✉️ **אימייל** (`mailto:`) עם נושא ותוכן
- 📹 **FaceTime** (`facetime:`)
- 👤 **כרטיס קשר** — שם, טלפון ואימייל (לא חובה) בקישור אחד, עם כפתורי שיחה/וואטסאפ/SMS/אימייל לבחירת הנמען; הפרטים מקודדים ב-fragment של הקישור, לא נשמרים בשום שרת

לכל קישור שנוצר מופק גם **קוד QR** מקומי בדפדפן, עם הורדה כתמונת PNG — בלי שירות QR חיצוני.

הפעולות הן כאלה שאין להן מקבילה בקישור `https` רגיל; וואטסאפ נוסף בבקשת הבעלים דרך קישור ה-click-to-chat הרשמי.

## איך זה עובד

הקישור שנוצר מצביע לדף עם הפרטים ב-query string, למשל:

```
https://urlcallapp.github.io/urlcallapp/call/?phone=050-1234567&phone_code=%2B972
```

לקישור שיחה אפשר להוסיף גם שדה `name` (לא חובה), והשם יוצג בדף שנפתח מהקישור.

כשפותחים אותו, הדף מנסה להפעיל את ה-protocol מיד. חלק מהדפדפנים דורשים מגע של המשתמש,
ולכן תמיד מוצג כפתור גדול וברור כגיבוי.

## פרטיות

הכל קורה בדפדפן של המשתמש. אין שרת, אין שמירת מידע, אין עוגיות.
כל מי שמחזיק קישור כרטיס קשר או את ה-QR שלו יכול לקרוא את הפרטים שבו — אין בו סודות.
בלי build; ספריית ה-QR (`qrcode`, רישיון MIT) ארוזה מקומית ב-`vendor/`.
