# urlcallapp

קישורי HTTP לחיצים שמפעילים פעולות native במכשיר — בלי אפליקציה, בלי שרת, בלי הרשמה.

יוצרים קישור בממשק צבעוני, שולחים אותו, ומי שפותח מקבל מיד הצעה לפעולה:
- 📞 **שיחה** (`tel:`)
- 💬 **SMS** (`sms:`) עם אפשרות להודעה מוכנה מראש
- ✉️ **אימייל** (`mailto:`) עם נושא ותוכן
- 📹 **FaceTime** (`facetime:`)

רק פעולות שאין להן מקבילה בקישור `https` רגיל.

## איך זה עובד

הקישור שנוצר מצביע לדף עם הפרטים ב-query string, למשל:

```
https://urlcallapp.github.io/urlcallapp/?p=tel&phone=050-1234567&phone_code=%2B972
```

כשפותחים אותו, הדף מנסה להפעיל את ה-protocol מיד. חלק מהדפדפנים דורשים מגע של המשתמש,
ולכן תמיד מוצג כפתור גדול וברור כגיבוי.

## פרטיות

הכל קורה בדפדפן של המשתמש. אין שרת, אין שמירת מידע, אין עוגיות.
קובץ אחד (`index.html`), בלי תלויות ובלי build.
